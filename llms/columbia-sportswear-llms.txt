## APIs

- [Content Hub External API](https://columbia.developer.azure-api.net/api-details#api=4cad0e39673846b186038d3113e5a4ab): Read Columbia product imagery ("seasonal assets") by 10-digit material number or in bulk. OpenAPI 3.0.1, 2 GET operations, base https://api.columbia.com/ContentHubExternal. Unauthorized callers are limited to Product Shot imagery older than the configured season.
- [OpenAPI definition](https://github.com/api-evangelist/columbia-sportswear/blob/main/openapi/columbia-sportswear-content-hub-external-openapi.json): the contract as exported by Columbia's own API Management instance.

## Operations

- `GET /api/external/image/GetSeasonalAssets` — `get-api-external-image-getseasonalassets-materialnumber-materialnumber`. Required query parameter `MaterialNumber` (10-digit product number, e.g. 1442362613). Optional `Perspective`, `SubType`, `ModifiedOnStartRange`, `ModifiedOnEndRange`. Returns 200 with the assets, 400 when MaterialNumber is missing, 500 on an unexpected exception.
- `GET /api/external/image/GetSeasonalAssetsBulk` — `get-api-external-image-getseasonalassetsbulk`. Optional `Perspective`, `SubType`, `ModifiedOnStartRange`, `ModifiedOnEndRange`, `Skip` (default 0), `Take` (default 100). Returns 200 with Product Shot assets, 400 when Take exceeds 1000, 500 on an unexpected exception.

## Authentication

- An Azure API Management subscription key is required on every call. Send it as the `Ocp-Apim-Subscription-Key` request header, or as the `subscription-key` query parameter.
- There is no OAuth, OpenID Connect or bearer-token surface. Calls without a key return HTTP 401 with `WWW-Authenticate: AzureApiManagementKey`.
- Keys are issued per subscriber through the developer portal and every subscription requires Columbia's approval.
